# MQTT-Based Wireless Sensor Network Using ESP32 and Raspberry Pi

This repository presents the implementation of a Wireless Sensor Network (WSN) that utilizes the MQTT protocol for efficient and reliable real-time data transmission. The system employs ESP32-based sensor nodes for data acquisition and a Raspberry Pi configured as an MQTT broker to serve as the central communication hub.

Sensor nodes collect environmental or operational data and publish it to designated MQTT topics over a wireless network. The Raspberry Pi receives, manages, and distributes the data using MQTT's lightweight publish-subscribe architecture, enabling seamless communication between distributed devices and monitoring applications.

The proposed architecture provides a scalable, flexible, and low-cost solution for real-time sensor data collection, monitoring, and analysis. Its modular design facilitates the integration of multiple sensor types and supports a wide range of applications, including environmental monitoring, industrial automation, smart agriculture, and IoT-based research projects.

## Key Features

* ESP32-based wireless sensor nodes
* Raspberry Pi MQTT broker implementation
* Lightweight MQTT publish-subscribe communication
* Real-time sensor data acquisition and transmission
* Scalable and modular WSN architecture
* Easy integration of multiple sensors and devices
* Low-cost and energy-efficient deployment
* Suitable for IoT, environmental, and industrial applications
